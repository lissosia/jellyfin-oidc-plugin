Pocket ID sign-in

Connect Jellyfin to one OpenID Connect provider. The callback validates state, PKCE, nonce, issuer, audience, signature, and token lifetime before a one-use Jellyfin credential is issued.

Use HTTPS for normal use. HTTP is accepted only for localhost or private IPv4 test servers such as 10.x.x.x, 172.16–31.x.x, and 192.168.x.x.

Redirect URI to add to the Pocket ID OIDC client: Set the public Jellyfin URL to generate this value.

Who may sign in

Accounts are linked by the immutable issuer and subject values. Jellyfin accounts with a matching username are not silently linked.

Admin group mapping is disabled until you explicitly enable it. A local Jellyfin administrator is not demoted by this mapping.

Profile picture

Pictures are fetched from HTTPS on the configured Pocket ID host only. JPEG and PNG images are limited to 2 MiB and 4096 × 4096 pixels.

Try Pocket ID sign-in

This opens Pocket ID in a separate window. On return, Jellyfin creates or resolves the user, syncs configured access and profile settings, and establishes a normal Jellyfin browser session for that user.

Phase 0 mock login check

The temporary Phase 0 mock flow is disabled by default and should only be used on a private test server.
